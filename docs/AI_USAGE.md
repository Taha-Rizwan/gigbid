## Summary

GigBid was built with heavy help from **Claude Code** (Anthropic's Claude, running as a coding
agent in my terminal). I wrote the plan's decisions with it (`PLAN.md`, decisions D1–D29, which I
reviewed and changed in §0). I then ran several Claude Code sub-agents in parallel, each on one
area: GigSim, the web app, the data pipeline, the evaluations and the documentation. I directed
the work, set the scope cuts, reviewed the diffs, ran the drills and the tests, and decided what
shipped.

I am accountable for every line in this repository, including the lines an assistant wrote. If I
cannot explain a part of the system, that is my failure, not the tool's.

## One thing it got wrong that I caught

{{STUDENT: describe one real mistake in your own words: what the assistant produced, how you noticed, and the fix (with the file or commit). Candidates from this project:
- The phone-number regex in the PII mask and the Compliance Guard first matched year ranges such as "2019 - 2023" and protocol versions such as "2025-06-18" as phone numbers, so case studies were redacted. Fixed by requiring 9+ digits with no word or hyphen on either side (`common/security.py` `_PATTERNS`, `agent/config.yaml` `policy.forbidden_patterns.phone_number`).
- The CLI imported the Windows event-loop fix (`import common`, which sets the selector loop policy in `common/__init__.py`) after the event loop had already started, so the async Postgres pool hung. The fix is to import `common` before `asyncio.run(...)`. Before citing this one, check `agent/runner.py`: at the time of writing, `import common` still sits inside the `_cli()` coroutine.
- MCP tool errors came back from the adapter as plain text, and the first version treated that text as evidence or data. Fixed by raising on string results and parsing the JSON error payload (`agent/mcp_client.py` `AgentTools.call()`, `_tool_error()`).}}

## Other notes

- Prompts are in `agent/prompts/`, one versioned file per node. CI blocks inline system prompts
  (`scripts/ci_guards.py` `check_prompts`).
- No real client data, hidden-test data or tokens were given to any assistant. Secrets stay in
  `.env`, which is git-ignored and checked by `scripts/ci_guards.py`.
